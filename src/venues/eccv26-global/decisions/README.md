# User-required decisions

This list is only for decisions that cannot be settled from the ECVA source,
paper context, and a primary institutional source. It is not a backlog of
unresolved strings: routine spelling variants, aliases, and paper-context
disambiguation remain investigator work.

Each non-empty row must state the raw affiliation, the exact scope, viable
entities, why evidence did not decide, and the narrow policy or factual choice
required. An empty CSV body means no user intervention is currently needed.
